# 03 - SQL Analysis (PostgreSQL)

**Goal:** load the clean tables into PostgreSQL and answer business questions with SQL.

## Planned contents
- `schema.sql` - tables, primary and foreign keys
- `load_data.sql` - CSV loading
- `queries.sql` - business queries (top products, store ranking, customer value, promo impact)
- `results/` - exported query outputs

## Techniques to practise
Joins, CTEs, window functions (rank, running totals, month-over-month), aggregations.
