# 05 - Power BI Dashboard

**Goal:** a dashboard that tells the sales story to a non-technical retail manager.

1. Executive overview - revenue, margin, transactions, growth
2. Stores and products - rankings and category mix
3. Customers and payments - segments, loyalty, payment methods
4. Promotions - uplift and discount cost
5. Forecast - actual vs predicted demand
